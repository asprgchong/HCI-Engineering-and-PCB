## PCB Smart Glasses Project: 
Final Project for HCI PCB with Prof Lopes result
<img width="4032" height="3024" alt="glasses" src="https://github.com/user-attachments/assets/8c4cf654-26fa-4a59-8ef3-56a2c351c575" />

This class was an amazing experience into the harsh world of EE and prototyping. 
My idea was to create smart glasses from scratch that a user would interact with using gestures and a smart glasses product that would also react to the user's environment. 
During the KiCAD wiring and organization process, I had messed up the wiring of the SCL and SDA pins on the wrong pins on the SAMD21 processor which was a TQFP component hot gun soldered down. As depicted above, there is a stray wire running to the VCC pin on my OLED.
There were a lot of things that went wrong with this project and hence it's roughness. But I'm really proud of this project! 

I had no prior experience and I made a fully functioning smart glasses product that allowed the user to see the to-do list. I don't have my glasses anymore, they are with Prof Lopez but I am actively working on my mistakes and trying to make it better.
